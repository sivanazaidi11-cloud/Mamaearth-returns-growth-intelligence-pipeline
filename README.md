# Mamaearth Returns & Growth Intelligence Pipeline

**Capstone Project — Data Analytics with AI & Gen AI**  
**E&ICT Academy, IIT Roorkee**

## 1. Project Objective

This project builds an end-to-end analytics pipeline for Mamaearth using customer, product and order data.

The pipeline has three layers:

1. **SQL** — schema, loading and business reports.
2. **Python** — data cleaning, EDA, verified metrics and visualizations.
3. **GenAI** — converts only verified Python findings into an executive business narrative.

The source CSVs are preserved as the raw input layer. Cleaning is performed in Python and is never performed by manually editing the source CSV files.

## 3. Data Quality Issues Intentionally Handled

The raw order data contains realistic data-quality issues:

- inconsistent payment-method casing such as `COD`, `cod`, `Card`, `card`, `CARD`, `UPI` and `upi`
- missing `discount_pct`
- missing `rating`
- five duplicate business rows represented by O0176–O0180 with different order IDs
- the source CSVs are not manually altered to fix these issues

Cleaning rules:

- payment methods are standardized to uppercase
- duplicate business rows are removed using all order attributes except `order_id`
- missing discount percentage is imputed with the median of the cleaned order data
- missing ratings are imputed with the median rating
- gross value = quantity × product price
- discount amount = gross value × discount percentage / 100
- net revenue = gross value − discount amount

For this dataset, the duplicate removal removes five rows and the median discount used for imputation is 20%.

## 4. How the Data Flows

```text
Raw CSV files
     |
     v
SQLite schema + seed
     |
     v
SQL reports
     |
     v
Python cleaning + EDA
     |
     +----> PNG visualizations
     |
     +----> narrator/findings.json
                    |
                    v
              Gemini narrative
```

The GenAI layer never reads the raw CSVs directly. It reads `narrator/findings.json`, which is generated by the Python analysis layer.

## 5. Requirements

Python 3.10+ is recommended.

Install:

```bash
pip install pandas matplotlib google-genai
```

SQLite is also required for the SQL layer.

## 6. Exact Run Order

Run all commands from the repository root.

### Step 1 — Create the SQLite database

```bash
sqlite3 mamaearth.db < sql/schema.sql
```

### Step 2 — Load the CSV data

```bash
sqlite3 mamaearth.db < sql/seed_data.sql
```

### Step 3 — Run SQL business reports

```bash
sqlite3 mamaearth.db < sql/reports.sql
```

### Step 4 — Run Python cleaning and EDA

```bash
python analysis/clean_and_eda.py
```

This creates:

```text
narrator/findings.json
```

### Step 5 — Generate the required visualizations

```bash
python analysis/visualize.py
```

This creates:

```text
visualizations/return_rate_by_payment.png
visualizations/monthly_revenue_trend.png
```

### Step 6 — Generate the GenAI narrative

Set your Gemini API key.

Windows PowerShell:

```powershell
$env:GEMINI_API_KEY="YOUR_API_KEY"
```

macOS/Linux:

```bash
export GEMINI_API_KEY="YOUR_API_KEY"
```

Then run:

```bash
python narrator/generate_narrative.py
```

Optional model override:

```bash
export GEMINI_MODEL="gemini-2.5-flash"
```

## 7. Verified Dataset Results

The Python pipeline verifies:

- Source order rows: **180**
- Duplicate business rows removed: **5**
- Cleaned orders: **175**
- Returned orders: **44**
- Overall return rate: **25.14%**
- Net revenue after discounts: **₹95,638.70**
- Average order value: **₹546.51**

The highest return-rate payment method is **COD at 44.44%**.  
The lowest return-rate payment method is **CARD at 14.71%**.

The highest-revenue category is **Haircare**, with **₹42,520.80** in net revenue.

The highest-return-rate product is **Baby Shampoo**, with a **66.67%** return rate in this dataset.

These values are generated by the Python pipeline and stored in `narrator/findings.json`.

## 8. Data Integrity Rule

The source CSV files must not be manually cleaned before analysis.

The intended workflow is:

```text
raw data → SQL → Python cleaning → verified findings → GenAI narrative
```

This keeps the pipeline reproducible and makes it clear which layer produced each number.
